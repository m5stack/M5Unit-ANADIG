◆ storeBothVoltage()

bool m5::unit::UnitGP8413::storeBothVoltage ( )

Store the current output voltage to the chip.

The stored voltage is output when the chip is powered on (until the output is written again). The store sequence cannot be generated by the I2C controller, so the I2C bus is released and the sequence is bit-banged on the SDA/SCL pins, then the bus is restored. Supported buses: Arduino TwoWire (including the LP I2C Wire1, e.g. NessoN1 Hat port), m5::I2C_Class (M5.Ex_I2C etc.), M5HAL software I2C, ESP-IDF native I2C drivers, and via a hub (PaHub etc.) connected to one of these

Returns
True if successful. False if the chip does not acknowledge the store sequence (e.g. not connected)
Warning
Not supported on the ESP-IDF native I2C drivers when the pins are not routed through the GPIO matrix (LP I2C) (returns false)
Other devices on the same bus cannot be accessed during the store (about 10 ms). Blocked until complete
Note that the output range is not stored
Note
The chip has no read command, so the stored value can only be checked by power-cycling the unit and measuring the output
